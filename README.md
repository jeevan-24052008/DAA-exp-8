# Experiment 8: Travelling Salesman Problem

## 📌 Aim
To find the minimum-cost tour for the Travelling Salesman Problem.

## 📝 Description
This program generates possible tours for a given set of cities and identifies the tour with the minimum travel cost. It accepts a cost matrix and displays the optimal route along with its cost details.

## 🛠️ Technique Used
- Brute Force
- Permutation
- Tkinter GUI
